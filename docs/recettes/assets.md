# Assets : licences et crédits

Les méthodes de production : `sons-et-musique.md` (sons et musiques ; le jeu est en 2D depuis G0, la recette des modèles 3D a été retirée). Ce fichier garde ce qui vaut pour tous les assets.

## Licences et crédits

- Une ligne dans `assets/LICENSES.md` à l'entrée de chaque asset : fichier, source (lien), auteur, licence, texte de crédit exigé entre « » après « crédit obligatoire : », usage d'IA (outil, licence commerciale, retouches).
- Même un asset CC0 a son auteur noté (crédit de courtoisie).
- L'écran de crédits peut être généré depuis ce fichier (`make credits` dans River Cleaner) : une seule source.
- Avant la sortie : questionnaire de contenu IA de Steamworks, licences des polices jointes au jeu (OFL), crédits du moteur.
